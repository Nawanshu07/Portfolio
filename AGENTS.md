# Portfolio Agent Guide

## Required reading

Before changing this repository, read `DESIGN.md`, `docs/PROJECT.md`, `docs/INFO.md`, `docs/TASKS.md`, `docs/PROGRESS.md`, and `docs/DECISIONS.md`.

## Working agreement

- `docs/INFO.md` is the content source of truth. Do not invent personal facts, metrics, credentials, links, or testimonials.
- Build an original portfolio. The Dennis Snellenberg site is an interaction and quality reference only: do not copy its layout, wording, branding, imagery, or code.
- Preserve uncommitted user work. Do not restore, discard, or commit unrelated changes without explicit approval.
- Keep the site accessible, responsive, and usable with reduced motion.
- Prefer small, focused changes. Avoid adding dependencies unless they solve a demonstrated need.

## Handoff

Before ending a task, update `docs/TASKS.md` and `docs/PROGRESS.md`, record tests actually run, list modified files, and note anything incomplete. Never call unverified work complete.
