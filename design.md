# Brutalist Developer Portfolio — Design Specification

## Vision
Stripped-back, factual, zero-bullshit developer portfolio. No glows, no soft shadows, no bubbly gradients. Pure black canvas, sharp borders, monospace metadata, raw information density.

## Color System
| Token | Value | Usage |
|---|---|---|
| bg | #050505 | Page background |
| bg-card | #0a0a0a | Card surfaces |
| bg-elevated | #111111 | Hover / active surfaces |
| border | #27272a (zinc-800) | All 1px borders |
| border-hover | #3f3f46 (zinc-700) | Hover state borders |
| border-active | #fafafa (zinc-50) | Active / accent border |
| text | #e4e4e7 (zinc-200) | Body text |
| text-strong | #fafafa (zinc-50) | Headings, emphasis |
| text-muted | #71717a (zinc-500) | Metadata, secondary |
| text-dim | #52525b (zinc-600) | Timestamps, labels |

## Typography
- Headings: Inter, font-medium, tight tracking
- Body: Inter, font-normal, zinc-200
- All metadata, tags, nav links, timestamps: JetBrains Mono

## Layout Rules
- Border radius: rounded-sm (4px) max. No rounded-xl, no rounded-full on cards.
- Tight grid gaps: gap-3 or gap-4 max.
- No soft shadows. No glows. No blur effects on backgrounds.
- 1px borders only. border-zinc-800.

## Copy Rules
- No buzzwords
- State facts: BCA student, C/C++/Python/DSA, web dev
- Direct and blunt
